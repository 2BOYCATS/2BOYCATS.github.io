# สุรพัตร์ หน่ายสังขาร — Portfolio
 
เว็บไซต์ Portfolio ส่วนตัวของนักศึกษาวิทยาการคอมพิวเตอร์ที่สนใจงานพัฒนา Front-end รวบรวมโปรเจกต์ ทักษะ และประสบการณ์ไว้ในที่เดียว จัดทำขึ้นเพื่อประกอบการสมัครสหกิจศึกษาตำแหน่ง Frontend Developer
 
**🔗 [เปิดดูเว็บไซต์](https://2boycats.github.io/)**
 
## เนื้อหาในเว็บไซต์
 
| ส่วน | รายละเอียด |
| --- | --- |
| หน้าแรก | แนะนำตัว พร้อมปุ่มไปยังโปรเจกต์และช่องทางติดต่อ |
| เกี่ยวกับฉัน | ที่มา ความสนใจ และเป้าหมายด้าน Front-end |

| Featured Projects | โปรเจกต์ที่คัดมาแสดง พร้อมรูป คำอธิบาย เทคโนโลยี และลิงก์ไปยัง GitHub ของแต่ละโปรเจกต์ |
| ประสบการณ์ | ประสบการณ์ทำงานนอกห้องเรียน |
| ติดต่อ | ช่องทางติดต่อ และ QR Code สำหรับ LINE |
| ดาวน์โหลด CV | ไฟล์ CV ในรูปแบบ PDF |

## Tech Stack
 
- HTML, CSS, JavaScript
- GitHub Pages (โฮสต์)
## รันในเครื่อง
 
```bash
git clone https://github.com/2BOYCATS/2BOYCATS.github.io.git
cd 2BOYCATS.github.io
```
 
จากนั้นเปิดไฟล์ `index.html` ด้วย Live Server ใน VS Code (หรือดับเบิลคลิกเปิดในเบราว์เซอร์ก็ได้)
 
## โครงสร้าง
 
```
.
├── index.html
├── images/       # รูปโปรไฟล์ รูปตัวอย่างโปรเจกต์ QR Code
└── documents/    # ไฟล์ CV (PDF)
```
